Python

Python é uma linguagem de programação versátil e popular que serve para criar programas, automatizar tarefas e analisar dados. É utilizada em diversas áreas, como ciência de dados, inteligência artificial, desenvolvimento web e automação.

JavaScript

JavaScript (JS) é uma linguagem de programação que permite adicionar interatividade a páginas da web. É a linguagem mais popular do mundo, segundo a Pesquisa de Desenvolvedores do Stack Overflow de 2022

Django Framework

Django é um framework de desenvolvimento web que permite criar aplicações web de forma rápida e eficiente. Ele é escrito em Python, uma linguagem de programação popular e relativamente fácil de aprender.
